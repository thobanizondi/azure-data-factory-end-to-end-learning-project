# azure-data-factory-end-to-end-learning-project
Hands-on Azure Data Factory project focused on building cloud-based ETL/ELT pipelines. Implemented incremental data loads using watermark patterns and parameterised pipelines. Integrated Azure SQL, ADLS, Databricks, Synapse, Logic Apps, and Key Vault. Practised monitoring, error handling, event triggers, and GitHub CI/CD.
